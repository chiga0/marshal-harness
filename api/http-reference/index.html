    HTTP 操作与 Schema¶

    本页由唯一 OpenAPI 自动生成，操作、请求、响应和 Schema 不维护第二份手写副本。

    下载 OpenAPI 3.1 · 标准契约语义 · 版本支持

    合同版本：0.1.0-candidate；27 个操作，77 个 Schema。HTTP 版本标识不等于软件发行版本或全量稳定承诺。
