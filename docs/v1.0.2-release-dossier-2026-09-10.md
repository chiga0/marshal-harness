## 明确未包含的能力

首次启动服务仍需可信 `--config`。Agent 文件检测不等于 Adapter、模型登录、业务工具、Leader 或交付权限已经配置完成。本次不能宣称零配置完成任意业务，亦未重新验证 DataAgent 的 ETL、发布或补数据。

本发行是 Node 服务源码资产，不包含 Go 原生二进制或构建后的 UI。后续页面修复与本地未提交工作不混入候选。历史 v1.0.0、v1.0.1 的资产及签名不覆盖。

## 安装后验收范围

确认安装成功后，检查初始化报告中的 Agent 入口和启动命令；先用 `marshal status` 检查连接。未配置服务时，使用 `marshal serve --config /absolute/trusted/config.mjs` 首次启动；后续使用 `marshal serve` 复用已保存配置。命令发生冲突时使用新安装根下 `packages/task-local/main.mjs` 的 Node 入口，不删除或覆盖未知命令。

业务验收须另行确认 Provider、需求、授权和独立检查条件；安装成功不是业务验收通过。
