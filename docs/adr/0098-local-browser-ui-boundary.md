# ADR 0098：可选本机浏览器 UI 访问边界

- 状态：Proposed（设计审查候选，尚未接受或实现）
- 日期：2026-09-10
- 关联：ADR0085、ADR0088、ADR0094、ADR0097；UI-1 设计包

## 背景

当前 protect 拒绝任何非空 Origin；客户端依赖 Node 模块。浏览器 UI 不能通过隐藏代理剥除 Origin 来绕过此保护。本提案仅扩展显式启用的本地 UI 模式，保留 API-only 与唯一 Application/SQLite、原任务授权和预算。

## 决策提案

1. 同一 Node 服务显式 opt-in UI 模式，监听仍只允许 127.0.0.1；启动参数建议 `--ui`，最终须与现 CLI 解析核对。静态路径 `/ui/`，浏览器 hash 路由。未开启时不托管 UI，原非空 Origin 拒绝规则不变。
2. UI 模式为每次实际绑定端口计算唯一 `http://127.0.0.1:PORT`。Host 必须精确相等且单值；非空 Origin 必须精确等于此值且单值。拒绝 `null`、外站、相似后缀、任意端口/主机和通配。无 Origin 的原 Node 客户端保持原 Host/Bearer 检查。
3. `/v1` 继续要求原 Bearer；同源不等于授权，不引入 cookie 或账号/session 权威。浏览器用户从本机既有连接信息取得 token，手动输入，仅内存保存；URL、Web Storage、IndexedDB、日志、构建产物均不得存 token。断开/刷新清除 token；连接只指向当前 origin，不接收任意远程 baseURL。
4. 不返回通配 CORS，不引入跨站预检许可。开发预览用无秘密合同样例；真实接入与 E2E 使用构建后的同源 UI，不能靠 Vite proxy 去除 Origin 完成验收。
5. 静态资源不需 Bearer但不含实例秘密；只允许发行清单中的静态文件。路径解码/遍历/符号链接逃逸拒绝；GET/HEAD只读，错误不回显宿主路径。CSP 限制脚本/连接为自身、禁止对象和第三方 framing，不使用 eval；制品不能作为同源活动网页执行。敏感API响应no-store，HTML不缓存，hash资源可缓存。
6. token 全权访问风险保持可信单用户边界，不宣称 XSS/同 UID 恶意代码隔离；必须净化渲染、限制外部资源。页面不读取服务器任意文件或SQLite，不自行执行 shell。
7. 浏览器只消费公开合同；Task actions、Worker取消、Leader答复各按原合同判断。客户端摘要由 Web Crypto/纯模块计算，保留原串绑校验。不能重写服务端 revision、替换批准摘要或自动重试未知副作用。
8. 未决命令的原 key/body/绑定信息在当前页面内存保留，离开/刷新前有未决命令时提示可能需人工核对。离开警告仅尽力，浏览器崩溃不保证触发。刷新后全部请求上下文已丢失，不自动恢复/重发 mutation，也不能声称识别具体未决请求。每次重新连接一律提示核对上次中断操作，查询可观察Task与回执；如创建结果无法定位，人工核对，不能自动新建。首版不持久化敏感命令正文；这是一项明确恢复限制。

## 兼容与替代

原 API-only、旧 Go profile、任务状态/数据格式和发布授权不变。只读 UI 不自动启用命令权限。BFF/HttpOnly会话可另提后继，但本轮避免增加会话和代理状态。远程部署/反向代理不在本提案支持面。

## 接受与验收

独立安全/合同审查关闭阻塞项后由维护者接受提案；接受记录绑定文档提交，不用本文件的 Proposed 当实现授权。实现需真实浏览器同源成功、跨站/Host反例、旧客户端、token泄露与制品脚本/路径边界检查，以及同包安装验证。全部场景见 UI-1 验收文档；目前未运行。
