## 已定默认值

本地单用户、中文、Web 桌面优先；React/TypeScript/Vite，语义化主题与 shadcn 基础组件；同一 Node 进程可选托管静态 UI；任务详情优先。正式服务的唯一 OpenAPI 是机器合同。首次连接手动提供 token，内存保存，不建设账号平台。

UI-1 的承诺是服务已配置业务能力内的任务全流程，不是任意 prompt 都可零配置执行。支持 Pi/Qwen 的情况以服务实际能力与验收结果为准。
