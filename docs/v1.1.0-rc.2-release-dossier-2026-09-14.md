## 发布说明草稿

- 无显式配置的新服务可通过 `marshal serve` 使用内置 Qwen 通用文件团队；支持记录实际 Agent 可执行入口，不要求用户手写业务配置。
- 支持 `--ui`、`--no-ui`、`--port`、`--data-dir`、`--agent-executable`。启动后记录连接文件并显示真实服务/UI 地址，客户端继续通过本地连接记录连接，不公开 token。
- 显式 `init --replace-launcher` 支持受控升级既有未修改 Marshal 启动器；`serve --generic` 显式选择通用配置。旧配置、旧数据不删除，服务活跃或状态不确定时拒绝替换和配置切换，未就绪不等于已停止。
- 修复 Leader 在交付已经完成后仍被示例引导重复 `deliver` 的问题：相应上下文明确要求 `conclude`，不绕过 Core 的交付和证据门禁。

本范围是可信单用户的通用文件交付：Leader 规划、两个互补作者、独立 Review、固定程序读取实际文件核验并收集交付物。**不是 ETL、生产发布、补数据或外部效果验收能力的默认启用**；登录 Qwen 不自动授予外部业务发布权限。设计边界见 [ADR0100](adr/0100-generic-team-default-and-agent-entry.md)。
