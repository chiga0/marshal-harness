## 发布门禁状态

- **stable v1.\* fail closed**：release workflow 对非 prerelease tag 在无签名 secrets 时直接 `::error::` 阻止（`a06189c`）
- **unsigned prerelease 允许**：含 `-` 后缀的 tag（如 `v1.0.0-rc1`）可产出 unsigned prerelease，release notes 自动标注 unsigned
- **Issue #212**：macOS 签名身份未 provision（企业策略阻断），为唯一外部发布阻塞；不影响 prerelease 通道

## 已知限制（prerelease 范围）

1. **lease 非耐久**：DispatchLease 仍是内存态，进程重启即丢失（`V1-LEASE-NOT-DURABLE` OPEN）
2. **agent/sandbox digest 刚分离**：Facts 已新增 `SandboxCapabilityDigest` 字段，但完整双 binding 校验需进一步适配 bindingcheck
3. **ResultIngress 非耐久**：replay/idempotency 状态是进程内 map（`V1-RESULTINGRESS-NOT-DURABLE` OPEN）
4. **真实 pi 全闭环未验证**：`TestRealPiStrictE2E` 已建但未用真实 pi 验证通过
5. **TestTaskRunUsesFrozenFallbackAdapter**：b4ecea2 上的既有 pre-existing failure（非本次修改引起）
