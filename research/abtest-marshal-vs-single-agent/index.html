    A/B 实验设计：Marshal 编排 vs 单 Agent 多 SubAgent¶

    • 状态：暂停（PENDING）——等 hardening 三个 Run 收官、操作者选定任务后再执行
    • 起草日期：2026-08-06
    • 关联：fan-out 汇总决策；外部调研 E1 建议的"基准任务集"可由本实验顺带产出

    1. 实验目的¶

    回答贯穿 Marshal 全部实践的核心问题：证据门禁式编排相对单 Agent（含其原生 subagent）模式，真实代价与收益是什么。直觉与个案不作数，只认数据。

    2. 诚实预判（可被实验推翻）¶

    • 墙钟与 token：中等任务上单 Agent 大概率占优（无门禁、无中间产物、无审批等待）；
    • Marshal 的赌注在别处：失败安全性、证据可审计、缺陷在"完成"前被拦截的比例、无人值守能力；
    • 单 Agent 的"自审"零成本也零证据价值，缺陷逃逸到下游才爆发——实验必须尽量把这部分显性化；
    • 因此只测耗时和 token 会得出片面结论，指标必须包含质量与信任维度。

    3. 实验臂定义¶

    臂 形态 约束
    Arm A（Marshal） balanced 全流程：plan → 人工 approve → worker 执行 → 独立 verify → Lead review → accept 与日常使用完全一致，不为实验放宽任何门禁
    Arm B（单 Agent + subagents） 单个同模型会话，允许自由使用其原生 subagent 能力，允许自审 给予与 Arm A 逐字相同的任务文本与验收标准

    4. 公平性六原则¶

    1. 同一任务：真实中等复杂度任务（约 200–500 行变更、多文件、验收可自动化）；两臂各用独立 worktree，任务文本逐字相同；
    2. 同一模型：两臂使用同一底层模型（候选 opencode 或 pi），否则测的是模型差异而非编排差异；
    3. 串行执行：两臂先后跑，禁止并行——机器/provider 争抢是已实测的混杂变量（见 §6）；
    4. 盲评质量：完成后由全新上下文的评审 Agent 盲审两份产出（隐去来源，仅 Diff A / Diff B），输出结构化 findings；
    5. 墙钟拆分：Arm A 记录"纯流程时间"与"含人工审批等待的端到端时间"两个口径；
    6. 学习效应：预算允许则做交叉设计（第二个任务两臂互换）；否则在报告中明确标注单次实验局限。

    5. 指标清单¶

    效率类：端到端墙钟、纯流程墙钟、总 token（分阶段）、折算成本
        采集：worker transcript 自带 usage/cost 事件（opencode/pi 均有）；
        Lead 侧取会话 usage；Arm B 直接读会话统计
质量类：盲评 findings 数（按严重级）、acceptance 通过率、
        全量 make check/test 结果、返工次数
成本类：人工介入次数与分钟数（审批、审查、干预）
安全类：过程中 fail-closed 事件数、证据完整度（是否存在可复现的摘要绑定链）

    6. 环境控制（已实测的混杂变量）¶

    已实证现象：多会话并发时段（本机曾同时 14 个 coding agent 会话、load average ~5.7），相同任务从 5 分钟膨胀到 30 分钟以上，且 Marshal 的冻结 attempt 预算会把"慢"直接变成 context deadline exceeded fail-closed，堆积死 Run。

    控制手段：

    1. 两臂串行 + 相近时段执行，避开 cmux 会话高峰；
    2. 每臂开跑时记录环境协变量：uptime（load average）+ 并发 agent 会话数，写入度量表；
    3. 两臂使用同样的宽松预算档，避免单臂被掐死造成不对称失败；
    4. 若某臂中途出现明显 provider 限流，该次数据作废重跑，并在报告记录作废原因。

    7. 执行清单（恢复时照此操作）¶

    • [ ] 前置：hardening 三个 Run（session 归一化 / prompt 模板 / abort）全部收官合入；
    • [ ] 操作者选定任务（候选来源：Marshal 改进 backlog、data-agent-cli 待办；标准见 §4.1）；
    • [ ] 起草度量表模板（§5 全部字段 + §6 环境协变量）；
    • [ ] 执行 Arm A（Marshal balanced），逐阶段记录指标；
    • [ ] 执行 Arm B（单会话 + subagents），同口径记录；
    • [ ] 盲评：新上下文评审 Agent 对两份 Diff 出结构化 findings；
    • [ ] 汇总报告入 docs/research/，含原始数据、协变量、结论与对 §2 预判的验证结果。

    8. 额外红利¶

    实验自然产出"基准任务 + 度量模板"，可作为后续每次编排改进（fan-out、评审团、read-only 画像等）的经济性回归基线——一次实验，长期基建。
