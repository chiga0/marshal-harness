    v1.0.1 Node 22 兼容发行记录¶

    状态：v1.0.1 已发布。维护者交互签名后，固定公钥验签及两项摘要核对通过；新版本不覆盖 v1.0.0。

    范围与边界¶

    本次为 Node 运行时兼容补丁：按 ADR0097 接纳 Node 主版本至少22，不设上限；启动时校验必要 SQLite 能力。Node22.22.1 缺少 SQLite defensive，运行时明确告警，固定 SQL、外键、事务、秘密保护和默认未授权交付不变。不修改 HTTP Schema 或持久化格式，不增加 Agent 权限，也不宣称所有未来 Node 版本已经实测。

    用户环境的 Node22.22.1 是本次重点验证版本。模型登录及 Qwen 配置继续由用户提供，本次安装不启动模型、不复制凭据。旧 v1.0.0 的真实模型与长期样本属于其原始 sourceHead，不冒充本补丁新增的真实模型验收。
