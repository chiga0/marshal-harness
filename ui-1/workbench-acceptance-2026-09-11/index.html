    本批交付¶

    • 任务列表与卡片两种布局共用真实 HTTP 数据、搜索、筛选与分页；切换不生成任务、不请求另一套演示数据。空数据、失败和旧数据分别呈现。
    • 任务概览及独立 DAG 页接入已有 Graph API：节点状态、依赖边、角色、关联 Worker 与节点详情；提供可访问的列表替代。无计划时显示缺失，不推测 DAG、百分比或验收成功。
    • 设置移至独立页面，分通用、连接与安全、关于；主导航底部入口，保留任务、Graph 及 Worker 详情的安全返回路径；支持深浅主题和窄屏。
    • 未新增 Agent/Sandbox 配置写入接口或伪表单，未改变后端合同、权限与生命周期。

    验证与审查¶

    • 集成代码 3f990bbc：npm run build 成功；npm test 29 文件、285 项通过，包括真实 HTTP/SQLite 配合明确受控 fixture 的测试。测试 fixture 不作为产品运行数据或失败回退。
    • 作者互斥 worktree；列表与设置由集成者独立审查，DAG 由另一作者独立审查，集成测试接口补齐另行只读确认。无阻塞 P0/P1。
    • 真实浏览器连接本轮新建的真实本地服务，未创建任务、启动模型或写入业务资源。检查桌面 1440×1000、窄屏 375×812 的任务空态、模式切换、设置导航、返回、深浅主题；未发现阻塞性布局问题。
    • 浏览器构建包含全部本批视觉功能；最后的 Worker 返回路径收敛由最终构建及路由测试覆盖。服务使用启动时的静态资源快照，部署更新需重启服务。
